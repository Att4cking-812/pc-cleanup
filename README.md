# Уборка компьютера

Аккуратная очистка Windows без агрессивных «оптимизаторов»: временные файлы пользователя и системы, кэш установщиков Windows и корзина. Личные файлы не трогаются.

## Запуск

Двойной клик по `Уборка.cmd` или:

```powershell
powershell -ExecutionPolicy Bypass -File .\cleanup.ps1
```

Скрипт сначала показывает, сколько места занято, и спрашивает подтверждение. Нужно ввести `ДА` — иначе ничего не удалится.

## Что чистит

- `%TEMP%` — временные файлы пользователя;
- `%SystemRoot%\Temp` — временные файлы Windows;
- `%SystemRoot%\SoftwareDistribution\Download` — кэш установщиков обновлений;
- корзину.

Отдельно показывает размер файлов в `Downloads` старше 30 дней, но **не удаляет их**.

## Лог

Результат каждой уборки сохраняется в `%LOCALAPPDATA%\CleanupLogs\cleanup_ГГГГ-ММ-ДД_ЧЧ-ММ.txt`.

## Требования

Windows PowerShell 5.1+. Для очистки системных папок может понадобиться запуск от администратора.
